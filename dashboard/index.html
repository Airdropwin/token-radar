300 pre-token protocols, ranked by implied value

The watchlist is the floor: every protocol with at least $50M of TVL and no token on record. The early radar adds every pre-token protocol below that floor, plus the 50 smallest pre-token protocols above it, so the board reaches 300 rows without letting a wrapped, staked or bridged product of a token that already trades outrank the genuine early rows. Implied value is a model, not a promise — and never a prediction of whether or when a token is issued.

How implied value is computed — model radar-2

One function scores every protocol, from the snapshot's own figures only. No protocol name is special-cased, and no row is hand-picked.

A protocol is called pre-token because its record carries no token — not proof it has none. Live-token protocols are set aside with their market caps, never ranked in the board. Nothing here is financial advice; farm at your own risk, and never pay to claim.
